Microsoft Teams — Protocol Handler Abuse

Any webpage can silently invoke Teams' 10 registered protocol handlers without user confirmation. Visiting this page from a Windows machine with Teams installed demonstrates that sip://, callto://, im://, and other schemes launch Teams directly — no browser confirmation dialog on Windows.

A4 Hidden iframe — Browser Dialog Bypassed ✓ CONFIRMED BYPASS

Setting a hidden <iframe src="im://…"> fires the Teams protocol handler without the browser showing any "Open in Teams?" confirmation dialog. All other methods (anchor link, window.location) trigger a browser confirmation prompt. The iframe route bypasses it. Teams is opened silently — the only signal is Teams appearing on screen. Can be dropped via XSS, ad injection, or any script execution on any page.
